## Prompt utilizado

Crie somente o HTML5 semântico, sem CSS e sem JavaScript, para uma landing page sobre jogos. Use header, nav, main,
três sections e footer. Inclua menu com links internos, apresentação, três cards informativos e um formulário
demonstrativo simples. Crie nomes de classes claros para que eu possa estilizar depois. Retorne o código completo e
não crie o CSS.

## Propriedades utilizados

- box-shadow - Uso: usado no header. Função: coloca uma sombra em volta da caixa, podendo mudar a sua direção, cor e o seu desfoque. Resultado: um sombreamento preto na parte de baixo do header foi aplicada, dando mais destaque ao cabeaçalho;
- z-index - Uso: usado no header. Função: podemos fazer com que o elemento se sobreponha em relação a outro elemento. Resultado: usei no header para que o seu sombreamento se sobreponha e, então, esteja visível;
- justify-content: space between - Uso: usado na nav. Função: Coloca, igualmente, os espaços entre os itens do flexbox. Resultado: A logo e a barra de navegação foram separadas
